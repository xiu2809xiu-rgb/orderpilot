## The short version

- One sprint is one week, Monday to Sunday. Sprint 1 is 26 Oct to 1 Nov 2026.
- Sprints set the rhythm and never cap the work. Whoever is free pulls the next ready story from the top of the backlog.
- One story, one issue, one branch, one pull request.
- Each person holds at most two pieces of work in progress.
- A reviewer of the day responds within one working day.
- The assessment releases are in Weeks 5, 13 and 18, and each one is tagged.

The Git rules are in [CLAUDE.md](../../CLAUDE.md#9-git-and-ai-rules), and the day-to-day steps are in [CONTRIBUTING.md](../../CONTRIBUTING.md#workflow).
