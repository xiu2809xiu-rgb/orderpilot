# Product pass screenshots

Every picture the product pass's stories took, as prompt 003 section 4 asks: each role's home page and main pages, at 1440 by 900 and at 390 by 844, in light and dark where a story took both. 231 pictures in all. Each story retook its own roles' pictures at its final commit. A last walk of all nine roles on main could not run on 2 Nov, because the Docker daemon on the build machine was stopped. CI's End-to-end smoke job checks every role's home and main pages on each pull request instead. Select a picture to open it at full size.

All data is synthetic demo data.
