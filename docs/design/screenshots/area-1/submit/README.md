## How they were made

- Each picture is named `<what>-<role>-<width>-<light|dark>.png`.
- The orders were made through the API as Support or typed in on the page, with Support's demo sign-in. Every picture of a submitted order, in the pages, the list, the peek and the board, shows the same order, SO-20261126-0008, which Support submitted through the API. Each role's picture is that role's own demo sign-in opening that order.
- The boards and lists show the data of the moment: the submit walk made other orders on the same stack, so counts such as "Not in the order flow 11" and "134 orders" differ from picture to picture.
- The stack's data is the synthetic demo set. Nothing here is real.
